# Mini Zapisnik Rezervacija

Web aplikacija za praćenje rezervacija sa dinamičkim bojama datuma, modalima za potvrdu plaćanja i čuvanjem bez osvežavanja stranice.

## Karakteristike
- Prikaz 10 godina unazad i unapred (prikazuje samo sačuvane unose).
- Dinamičke boje polja za datum u zavisnosti od blizine današnjeg dana (prošlo, crveno za 5 dana, žuto do 2 nedelje, zeleno, plavo, belo).
- AJAX čuvanje podataka i beleški bez refresha stranice.
